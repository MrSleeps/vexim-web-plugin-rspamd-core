# VExim Plugin RSpamd Core Module

[![Latest Version on Packagist](https://img.shields.io/packagist/v/mrsleeps/vexim-web-plugin-rspamd-core.svg?style=flat-square)](https://packagist.org/packages/mrsleeps/vexim-web-plugin-rspamd-core)

This module is designed to work with the [VExim Web UI](https://github.com/MrSleeps/VExim-Web-UI).

It is the core module for RSpamd support.

You need to install [VExim Web UI](https://github.com/MrSleeps/VExim-Web-UI) for this to work

[More information about this plugin can be found in the Wiki.](https://github.com/MrSleeps/VExim-Web-UI/wiki)

[Please add any issues to the main VExim Web UI issues page on GitHub.](https://github.com/MrSleeps/VExim-Web-UI/issues)
